# Sample Project

Placeholder for a generated example project. From Run B onward, running:

```bash
agentdesk new "Review Assistant para restaurantes"
agentdesk plan
```

will populate a project folder here with `docs/`, `tasks/`, `prompts/`, `handovers/`, and
`agentdesk.json`. In Run A, project folders are created wherever you run `agentdesk new` (default:
current directory).
